# Бизнес-фича: Лобби — создание, подключение, выход, переподключение

## Проблема / Мотивация

Для начала игры компании друзей нужно собраться в одной виртуальной комнате.
Процесс должен быть максимально простым: один создаёт комнату, кидает код
друзьям, они подключаются. Если кто-то передумал — выходит, место освобождается.
Если во время игры у кого-то оборвалось соединение — он должен иметь возможность
вернуться, не ломая игру для остальных.

## Описание

### Создание лобби
1. Игрок вводит никнейм и нажимает «Создать игру».
2. Приложение создаёт лобби и показывает код комнаты (короткий, удобный для диктовки).
3. Создатель автоматически становится администратором и первым игроком в лобби.
4. Создатель видит экран ожидания с кодом комнаты и списком игроков.

### Подключение к лобби
1. Игрок вводит никнейм и код комнаты, нажимает «Присоединиться».
2. Если код верный и есть свободные места — игрок попадает в лобби.
3. Все игроки в лобби видят обновлённый список участников в реальном времени.
4. Подключение возможно только до старта игры.

### Выход из лобби (до старта)
1. Любой игрок может покинуть лобби до начала игры.
2. Место освобождается, другие игроки видят, что он ушёл.
3. Если администратор вышел, права передаются следующему игроку в списке.

### Переподключение (во время игры)
1. Если у игрока оборвалось соединение во время игры, он может вернуться.
2. Игрок заходит заново, вводит код комнаты и свой никнейм.
3. Приложение узнаёт его и восстанавливает сессию: роль, локацию, текущую фазу.
4. Новые игроки (которых не было при старте) подключиться к запущенной игре НЕ могут.

## Правила

Соответствует `docs/rules.md`, разделы 3.1, 3.3:
- Создатель = администратор.
- Подключение по коду приглашения.
- Минимум 3, максимум 8 игроков (по умолчанию).

Дополнительные уточнения:
- Выход до старта = полное удаление из лобби, место освобождается.
- Переподключение во время игры = по совпадению кода комнаты + никнейма.
- Новые игроки не могут присоединиться к запущенной сессии.
