# Бизнес-фича: Старт игры — распределение ролей и локации

## Проблема / Мотивация

После того как все собрались в лобби, нужно начать игру. Ключевой момент —
случайным образом определить, кто шпион, и показать остальным локацию, чтобы
они могли задавать наводящие вопросы. Шпион не должен знать локацию.

## Описание

### Готовность и старт
1. Каждый игрок в лобби нажимает кнопку «Готов».
2. Когда все игроки (>= минимум) готовы, администратор видит кнопку «Начать игру».
3. Администратор нажимает «Начать игру» — сессия стартует.

### Распределение ролей
1. Приложение случайным образом выбирает одного шпиона из всех игроков.
2. Остальные получают роль «Обычный игрок».
3. Шпион всегда один — множество шпионов не поддерживается.

### Определение локации
1. Приложение случайным образом выбирает одну локацию из предустановленного набора.
2. Локация одинакова для всех обычных игроков в рамках сессии.

### Что видит игрок после старта
- **Обычный игрок** видит на экране: название локации (крупно) и свою роль.
- **Шпион** видит на экране: надпись «Вы — шпион» (крупно). Локация НЕ показывается.
- Все игроки видят список участников сессии.

### Определение очерёдности
1. Приложение генерирует случайный порядок ходов для фазы вопросов.
2. Порядок отображается всем игрокам.

## Правила

Соответствует `docs/rules.md`, разделы 3.3, 4.1:
- Все игроки должны быть «Готовы» для старта.
- Только администратор запускает игру.
- Один шпион на сессию.
- Локация выбирается случайно из набора.

## Открытые вопросы

Нет — все вопросы покрыты текущими правилами.
