# Architecture Decision Records (ADR)

Здесь хранятся записи об архитектурных решениях проекта.
ADR фиксирует контекст, принятое решение и его последствия.

Создаются ролью **Architect** при принятии неочевидных технических решений.

## Шаблон

```markdown
# ADR-NNN: [Заголовок]

Status: proposed | accepted | deprecated
Date: YYYY-MM-DD

## Контекст
Какая проблема или вопрос привёл к этому решению.

## Решение
Что решили и почему. Какие альтернативы рассматривались.

## Последствия
Плюсы, минусы, ограничения, что нужно учитывать в будущем.
```

## Именование

Файлы нумеруются последовательно: `001-title.md`, `002-title.md`, и т.д.
Заголовок — краткое описание решения на английском (в kebab-case).
