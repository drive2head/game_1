# Модели данных

Описание основных сущностей, используемых на backend и frontend.
Все названия полей соответствуют JSON-ключам, передаваемым по сети.

> Термины — см. [glossary.md](glossary.md).

---

## Player

Участник лобби.

| Поле | Тип | Описание |
|---|---|---|
| `id` | `string` (UUID v4) | Уникальный идентификатор, генерируется при создании или присоединении к лобби. |
| `nickname` | `string` | Отображаемое имя, 1–20 символов. |
| `isAdmin` | `boolean` | `true`, если игрок является администратором лобби. |
| `ready` | `boolean` | Статус готовности к старту сессии. |

---

## LobbySettings

Параметры лобби, редактируемые администратором до старта сессии.

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `minPlayers` | `integer` | `3` | Минимальное количество игроков для старта. |
| `maxPlayers` | `integer` | `8` | Максимальное количество игроков в лобби. |
| `locations` | `string[]` | предустановленный набор | Список названий локаций для текущего лобби. |
| `voteThreshold` | `float` | `0.5` | Доля игроков (от 0 до 1), необходимая для начала досрочного голосования. Округление вверх: `ceil(voteThreshold * totalPlayers)`. |
| `votingTimerSeconds` | `integer` | `30` | Время на фазу голосования (в секундах). |

---

## Lobby

Виртуальная комната. Центральная сущность, объединяющая игроков и сессию.

| Поле | Тип | Описание |
|---|---|---|
| `code` | `string` | Код приглашения (6 символов, латиница верхний регистр). Уникален. |
| `players` | `Player[]` | Список игроков в лобби. |
| `settings` | `LobbySettings` | Текущие настройки. |
| `state` | `LobbyState` | Текущее состояние: `waiting` (ожидание игроков) или `in_game` (идёт сессия). |
| `currentSession` | `Session \| null` | Текущая активная сессия. `null`, если лобби в состоянии `waiting`. |

### LobbyState (enum)

| Значение | Описание |
|---|---|
| `waiting` | Лобби ожидает игроков, настройка параметров. |
| `in_game` | Сессия запущена, игра идёт. |

---

## Session

Одна партия игры внутри лобби.

| Поле | Тип | Описание |
|---|---|---|
| `id` | `string` (UUID v4) | Уникальный идентификатор сессии. |
| `location` | `string` | Выбранная локация (скрыта от шпиона). |
| `spyId` | `string` | `id` игрока-шпиона. |
| `turnOrder` | `string[]` | Порядок ходов — массив `Player.id` в порядке очерёдности. |
| `currentTurnIndex` | `integer` | Индекс текущего активного игрока в `turnOrder`. |
| `phase` | `SessionPhase` | Текущая фаза сессии. |
| `voteProposal` | `VoteProposal \| null` | Текущее предложение о голосовании. `null`, если не инициировано. |
| `votes` | `Vote[]` | Голоса, поданные в фазе голосования. |
| `result` | `SessionResult \| null` | Результат сессии. `null`, пока сессия не завершена. |

### SessionPhase (enum)

| Значение | Описание |
|---|---|
| `question` | Фаза вопросов (основная). |
| `vote_proposal` | Идёт сбор голосов за досрочное завершение фазы вопросов. |
| `voting` | Фаза голосования — игроки выбирают подозреваемого. |
| `spy_guess` | Шпион угадывает локацию (после ошибочного обвинения). |
| `finished` | Сессия завершена, результаты определены. |

---

## VoteProposal

Предложение досрочно завершить фазу вопросов.

| Поле | Тип | Описание |
|---|---|---|
| `initiatorId` | `string` | `id` игрока, инициировавшего голосование. |
| `votesFor` | `string[]` | `id` игроков, проголосовавших «За». |
| `votesAgainst` | `string[]` | `id` игроков, проголосовавших «Против». |
| `threshold` | `integer` | Количество голосов «За», необходимое для перехода к голосованию (`ceil(voteThreshold * totalPlayers)`). |

---

## Vote

Голос одного игрока в фазе голосования.

| Поле | Тип | Описание |
|---|---|---|
| `voterId` | `string` | `id` голосующего игрока. |
| `suspectId` | `string \| null` | `id` подозреваемого. `null` означает «Воздержаться». |

---

## SessionResult

Итог сессии.

| Поле | Тип | Описание |
|---|---|---|
| `winner` | `"spy" \| "players"` | Кто победил. |
| `reason` | `ResultReason` | Причина победы. |
| `suspectId` | `string \| null` | `id` обвинённого игрока (если голосование состоялось). |
| `spyGuess` | `string \| null` | Локация, названная шпионом (если он угадывал). |

### ResultReason (enum)

| Значение | Описание |
|---|---|
| `spy_caught` | Шпион правильно идентифицирован голосованием → победа игроков. |
| `spy_guess_wrong` | Шпион ошибся при угадывании локации → победа игроков. |
| `spy_guess_correct` | Шпион правильно угадал локацию → победа шпиона. |
| `no_suspect` | Подозреваемый не определён (все воздержались / нет большинства) → победа шпиона. |
