# Глоссарий

Единый справочник терминов проекта. Все feature-спецификации и код ДОЛЖНЫ использовать
именно эти термины (включая английские идентификаторы в коде).

| Термин (RU) | Идентификатор в коде | Определение |
|---|---|---|
| Лобби | `Lobby` | Виртуальная комната, в которой игроки собираются перед началом сессии. Содержит список игроков, настройки и состояние готовности. |
| Игрок | `Player` | Участник лобби. Характеризуется никнеймом и уникальным идентификатором. |
| Администратор | `Admin` | Создатель лобби. Управляет настройками, может кикать игроков, передавать права администратора и запускать игру. Администратор одновременно является игроком. |
| Сессия | `Session` | Одна партия игры — от распределения ролей до определения победителя. Лобби может содержать несколько последовательных сессий. |
| Роль | `Role` | Назначение игрока в рамках сессии: `spy` (шпион) или `regular` (обычный игрок). |
| Шпион | `Spy` | Игрок, которому не показывается локация. Его цель — вычислить локацию или остаться неразоблачённым. |
| Обычный игрок | `Regular` | Игрок, который видит название текущей локации. Его цель — вычислить шпиона. |
| Локация | `Location` | Место действия сессии (например, «Больница», «Школа»). Выбирается случайно из настроенного набора. |
| Набор локаций | `LocationSet` | Список локаций, из которого случайным образом выбирается одна для текущей сессии. Настраивается администратором. |
| Код приглашения | `InviteCode` | Уникальный код, по которому игроки подключаются к лобби. |
| Фаза вопросов | `QuestionPhase` | Основная фаза сессии: игроки по очереди задают друг другу вопросы через внешнюю связь. Приложение управляет очерёдностью. |
| Активный игрок | `ActivePlayer` | Игрок, чья очередь задавать вопрос в текущий момент фазы вопросов. |
| Порядок ходов | `TurnOrder` | Последовательность, в которой игроки задают вопросы. Генерируется случайным образом в начале сессии. |
| Предложение голосования | `VoteProposal` | Инициатива любого игрока досрочно завершить фазу вопросов и перейти к голосованию. |
| Порог голосования | `VoteThreshold` | Настраиваемый процент игроков, которые должны проголосовать «За» досрочное голосование, чтобы оно началось (например, 50 %+1). |
| Фаза голосования | `VotingPhase` | Этап, на котором каждый игрок выбирает подозреваемого из списка или воздерживается. Ограничена по времени. |
| Подозреваемый | `Suspect` | Игрок, набравший абсолютное большинство голосов в фазе голосования. |
| Угадывание локации | `LocationGuess` | Право шпиона назвать локацию, если по результатам голосования был обвинён обычный игрок (ошибочное обвинение). |
| Настройки лобби | `LobbySettings` | Параметры, задаваемые администратором до старта: мин./макс. игроков, набор локаций, порог голосования, правило очерёдности. |
| Готовность | `ReadyState` | Статус игрока в лобби: готов (`ready`) или не готов (`not_ready`). Игра стартует, когда все игроки готовы. |
