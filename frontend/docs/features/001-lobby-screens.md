# Feature: Экраны создания, подключения и ожидания в лобби

Status: draft
Priority: high
Depends on: backend [001-lobby-creation](../../../backend/docs/features/001-lobby-creation.md), backend [002-websocket-lobby](../../../backend/docs/features/002-websocket-lobby.md)

## Context

Пользователю нужен интерфейс для создания лобби, присоединения по коду и ожидания
старта с другими игроками. Включает экран Home (создать/присоединиться) и экран Lobby
(список игроков, готовность, выход).

Бизнес-фича: [docs/features/001-lobby-management.md](../../../docs/features/001-lobby-management.md).

## Requirements

### Functional

#### Страница Home (`/`)

- ДОЛЖНА отображать два варианта: «Создать игру» и «Присоединиться».
- Для создания: поле ввода никнейма + кнопка «Создать». При успехе — редирект на `/lobby/{code}`.
- Для присоединения: поля ввода никнейма и кода комнаты + кнопка «Присоединиться».
  При успехе — редирект на `/lobby/{code}`.
- При ошибке — отобразить сообщение (например, «Лобби не найдено», «Лобби заполнено»).
- `playerId` ДОЛЖЕН сохраняться в `sessionStorage` после успешного создания/присоединения.
- Код лобби ДОЛЖЕН сохраняться в `sessionStorage` для переподключения.

#### Страница Lobby (`/lobby/{code}`)

- При загрузке ДОЛЖНА установить WebSocket-соединение к `/api/lobbies/{code}/ws?playerId={id}`.
- ДОЛЖНА отображать:
  - Код комнаты (крупно, для передачи друзьям).
  - Список игроков с индикацией: никнейм, онлайн/офлайн, готовность, админ-бейдж.
  - Кнопку «Готов» / «Не готов» (toggle).
  - Кнопку «Покинуть лобби».
  - Кнопку «Начать игру» (видна только администратору, активна когда все готовы и >= minPlayers).
- При получении WS-события `lobby_updated` — обновить список игроков.
- При получении WS-события `player_left` — обновить список.
- При получении WS-события `game_started` — перейти на `/game/{code}`.
- При нажатии «Покинуть» — отправить WS-команду `leave_lobby`, перейти на `/`.
- При нажатии «Готов» — отправить WS-команду `player_ready` с `ready: true/false`.
- При нажатии «Начать игру» — отправить WS-команду `start_game`.

### Non-functional

- WebSocket-соединение ДОЛЖНО автоматически переподключаться при кратковременном обрыве.
- UI ДОЛЖЕН быть отзывчивым (мобильные устройства и десктоп).

## UI Description

### Home (`/`)

```
┌──────────────────────────────────┐
│        Находка шпиона            │
│                                  │
│  Никнейм: [_______________]     │
│                                  │
│  [   Создать игру   ]           │
│                                  │
│  ──── или ────                   │
│                                  │
│  Код комнаты: [______]          │
│  [ Присоединиться ]             │
│                                  │
│  (сообщение об ошибке)           │
└──────────────────────────────────┘
```

### Lobby (`/lobby/{code}`)

```
┌──────────────────────────────────┐
│  Комната: XKRT9M     [Выйти]   │
│                                  │
│  Игроки (3/8):                   │
│  ● Алиса 👑  ✓ Готов             │
│  ● Боб        ✓ Готов            │
│  ○ Вика       ✗ Не готов         │
│                                  │
│  [ Готов / Не готов ]            │
│  [ Начать игру ] (только админ)  │
└──────────────────────────────────┘
```

Состояния:
- **loading** — «Подключение...» пока WS не установлен.
- **error** — «Не удалось подключиться. Вернуться на главную.»
- **waiting** — основное состояние.

## Acceptance Criteria

- [ ] Создание лобби: ввод никнейма → POST → редирект на `/lobby/{code}`.
- [ ] Присоединение: ввод никнейма + кода → POST → редирект.
- [ ] Ошибки REST отображаются пользователю.
- [ ] WebSocket устанавливается при загрузке `/lobby/{code}`.
- [ ] Список игроков обновляется в реальном времени.
- [ ] Кнопка «Готов» переключает статус.
- [ ] Кнопка «Начать» активна только для админа, когда все готовы.
- [ ] «Покинуть» → возврат на Home, место освобождается.
- [ ] `game_started` → переход на `/game/{code}`.
- [ ] `playerId` и `code` сохраняются в `sessionStorage`.

## Edge Cases and Error Handling

- **Перезагрузка страницы лобби** — переподключение по сохранённому `playerId`.
- **WS обрыв** — показать индикатор «Переподключение...», автоматический retry.
- **Невалидный код при прямом заходе на `/lobby/{code}`** — редирект на Home с ошибкой.

## Out of Scope

- Настройки лобби (количество игроков, набор локаций) — фаза 4.
- Кик игроков — фаза 4.
