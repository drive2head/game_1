# Feature: Экран игры — отображение роли и локации

Status: draft
Priority: high
Depends on: [001-lobby-screens](001-lobby-screens.md), backend [003-game-start](../../../backend/docs/features/003-game-start.md)

## Context

После старта игры каждый игрок должен увидеть свою роль и (если он не шпион) локацию.
Это начальный экран игровой сессии.

Бизнес-фича: [docs/features/002-game-start.md](../../../docs/features/002-game-start.md).

## Requirements

### Functional

- Страница Game (`/game/{code}`) ДОЛЖНА отображаться после получения `game_started`.
- При получении персонального события `role_assigned`:
  - Если `role == "regular"` — показать локацию крупным текстом.
  - Если `role == "spy"` — показать «Вы — шпион» крупным текстом, без локации.
- ДОЛЖНА отображать список всех игроков сессии.
- ДОЛЖНА отображать порядок ходов (`turnOrder`) с подсветкой текущего активного игрока.
- ДОЛЖНА отображать напоминание: «Не называйте локацию прямо!»
- При переподключении (reconnect):
  - Сервер пересылает текущее состояние через `lobby_updated` и `role_assigned`.
  - Страница ДОЛЖНА восстановить отображение роли и текущей фазы.
- Если `playerId` отсутствует в `sessionStorage` при заходе на `/game/{code}` — редирект на Home.

### Non-functional

- Роль и локация ДОЛЖНЫ быть визуально заметными — это ключевая информация.

## Acceptance Criteria

- [ ] После `game_started` происходит переход на `/game/{code}`.
- [ ] Обычный игрок видит локацию, шпион — «Вы — шпион».
- [ ] Отображается список игроков и порядок ходов.
- [ ] Текущий активный игрок подсвечен в порядке ходов.
- [ ] При переподключении экран восстанавливается.
- [ ] Без `playerId` в sessionStorage → редирект на Home.

## Edge Cases and Error Handling

- **Прямой заход на `/game/{code}` без контекста** — проверить `sessionStorage`, попытаться reconnect.
- **WS обрыв во время игры** — показать «Переподключение...», retry.

## Out of Scope

- Кнопка «Завершить ход» (фаза вопросов) — фаза 2.
- Кнопка «Предложить голосование» — фаза 2.
- Экран голосования — фаза 3.
